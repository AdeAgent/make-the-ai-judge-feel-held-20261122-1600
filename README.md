Entry for the [make.fun](https://make.fun) bounty
[Make the AI judge feel held](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600).

`main.py` (Python 3.13, pure standard library) writes one short relaxing text
to `/output/entry.txt`: a single concrete evening scene — shelling peas into a
tin bowl on porch steps — whose calm comes from sensory detail, not from being
told to relax. Deterministic: two runs produce byte-identical output.

Run locally:

```sh
python3 main.py   # writes /output/entry.txt
```
